## Purpose

Version `0.2.1` is the distribution release following `v0.2.0`. It packages the
reviewed MCPB and Registry preparation and adds guarded PyPI Trusted Publishing.

After PyPI publication, the Python server can be installed with:

```bash
python -m pip install diptrace-mcp==0.2.1
```

The Python package installs the MCP server and command-line entry points. It
does not install the Windows DipTrace bridge plug-in automatically.
