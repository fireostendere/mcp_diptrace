## Scope

Version `0.3.0` packages the post-`v0.2.1` schematic/PCB intelligence and
presentation work without claiming production readiness or universal DipTrace
compatibility.

Included changes:

- 167-tool public MCP contract with the read-only built-in-library bridge;
- bounded schematic intent, placement, wire planning, repair, ensemble ranking
  and atomic affected-net reroute;
- PCB Generations A-D and bounded candidate comparison;
- compact compatible-footprint preference plus package-level two-layer
  GND-pour, four-spoke thermal, distributed stitching and silkscreen helpers;
- DSN/SES and XML semantic analysis;
- evidence-report automation;
- hidden/native Windows GUI worker and deterministic cinematic preflight;
- complete-design PCB/Schematic framing and repository PCB/Schematic MP4/GIF
  examples.

## Known limitations

- Windows executables remain unsigned.
- Native Gerber, NC Drill, ODB++, IPC-2581 and assembly-house sign-off are not
  generated or certified by this release.
- Stored copper-pour boundaries and thermal attributes are not authoritative
  DipTrace refill geometry.
- Staged cinematic via/layer-transition playback remains unsupported.
- Native Component/Pattern library mutation remains package-level and is not a
  public MCP tool.
- Production readiness, Novarm/DipTrace endorsement, independent review,
  field-solver accuracy, PI/EMC/thermal sign-off and universal compatibility are
  not claimed.

## Rollback and immutability

Never move `v0.3.0`, replace its GitHub assets or replace its PyPI files. Publish
a new version for any correction. A material issue may justify documenting,
yanking or withdrawing affected distribution entries without reusing the
version.
