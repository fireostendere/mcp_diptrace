## Scope since v0.1.2

The 0.2.0 line is a substantial development release rather than a correction release. It includes:

- a Windows one-click Inno Setup installer, standalone onedir server, portable bundle, and safe Codex/Claude configurator;
- fail-closed installation ownership, rollback, uninstall, checksums, unsigned/signed verification gates, SBOM, and provenance auditing;
- a centralized MCP error boundary with stable public codes and redacted details;
- a project-owned AnyIO worker-thread boundary for all 159 registered MCP tools, with connected responsiveness probes;
- NetClass-aware routing and trace-to-trace clearance resolution with explicit partial-review reporting;
- removal of verbatim external reference extracts from public surfaces and a project-authored factual inventory path;
- explicit pending DipTrace 5.3 fixture and Q1 component-angle evidence status;
- the first service-facade decomposition pass, splitting the previous monolith into explicit typed domain services while preserving the public API and safety boundaries.

## Supported claims and limitations

The candidate may be described as an alpha/development-stage MCP server with an unsigned Windows installer path and guarded DipTrace XML workflows. It must not be described as:

- production-ready;
- independently reviewed;
- signed;
- universally compatible with DipTrace 5.x;
- validated for every registered tool or XML object;
- safe for component rotation without the pending Q1 evidence;
- a replacement for DipTrace's native EDA engine;
- endorsed by, affiliated with, or approved by Novarm/DipTrace; or
- complete manufacturing or fabrication sign-off software.

Runtime `get_capabilities` remains authoritative for a specific installation and document.
