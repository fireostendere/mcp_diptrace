## Why a major version

`2.0.0` breaks the published `0.4.0` contract in three ways:

- the public surface is 151 tools instead of 167. Thirty-one names are gone: twenty
  folded into `run_review(profile=...)` and other survivors after `v0.4.0`, eleven
  more in this version, replaced by `apply_plan` and by tools that already returned
  the same data. Fifteen tools are new. The mapping is in
  [MCP_TOOLS.md](../MCP_TOOLS.md);
- arguments are strict: an unknown argument is refused, write tools require
  `selector`, committing `sync_schematic_to_pcb` requires the schematic SHA, and a
  numeric net string is a name (`xml-id:<Id>` addresses an id);
- Python 3.11 is the minimum. Python 3.10 reached end of life in October 2026.

The detailed list is [CHANGELOG_NEXT.md](../../CHANGELOG_NEXT.md).

## What the candidate is tested for

Repository gates on the candidate commit:

- the full test suite on Linux (Python 3.11, 3.13, 3.12 with and without Shapely),
  macOS and Windows, with the 90% combined coverage floor;
- ruff, strict mypy, the frozen `tools/list` snapshot (151 tools), the discovery
  budget, documentation-state, compliance, privacy and release-artifact checks;
- the Windows bridge build, the Windows installer workflow and the native PCB
  platform workflow on DipTrace 5.3.5.1;
- the Linux and macOS clean-install workflows with DipTrace 5.3.5.1.

The registration refactor is checked separately: before the tool removals, the
complete `tools/list`, resource, resource-template and prompt descriptors of the
split server were byte-identical to the single-function server.

## Not claimed

These gates from [the manual roadmap](../../documents/MANUAL_ROADMAP.md) are open.
The version change does not pass them:

- **M1**, native acceptance of `add_copper_pours`, `delete_copper_pours` and

  but the strict comparison is still `FAIL` (22 to 20 raw endpoint records; GND
  `J1` and `J2` pad `1` are missing after re-export). Not waived;
- **M5**, named-client acceptance of the `2.0.0` contract. Codex CLI 0.167.0 passed
  discovery and calls on the 161-tool predecessor; no client has run the 151-tool
  surface or `apply_plan`. Claude Desktop is not rerun;
- native CAM from `run_native_export` is raw evidence, not inspected CAM or
  fabrication sign-off;
- the historical 12/12 manual matrix belongs to its recorded checkpoints and is not
  rerun for this candidate.

## Known limitations

- Windows executables remain unsigned development artifacts.
- The Linux and macOS installers pin the DipTrace build the vendor serves on
  2026-11-22. The vendor replaces that file in place, so the pin will fail again at
  the next DipTrace release; `DIPTRACE_VERSION`, `DIPTRACE_INSTALLER_URL` /
  `DIPTRACE_DMG_URL` and the matching SHA-256 variable override it.
- Native manufacturing sign-off, production readiness, Novarm/DipTrace endorsement,
  field-solver accuracy, PI/EMC/thermal sign-off and universal DipTrace
  compatibility are not claimed.
