## Scope

Version `0.4.0` packages the current roadmap closure and adds tested
cross-platform installation/GUI paths while keeping the public MCP contract at
167 tools.

Included changes:

- guarded whole-board PCB plan/apply with source/candidate SHA binding, preview,
  hard-review blocking, backup and rollback;
- provider-neutral reviewer evaluation, source-bound engineering-rule ingestion,
  source-bound bounded PCB physics estimates and hash-bound evidence campaigns;
- topology-preserving schematic reroute for proven connected acyclic literal
  wire topology, with fail-closed ambiguity/cycle handling;
- confidence-gated cardinal schematic rotation candidates and one atomic
  `delete wires -> rotate/move -> rebuild wires` package-level batch; automatic
  rotation remains disabled by default pending claim-specific evidence;
- Linux one-command installation with visible real DipTrace GUI and private-Xvfb
  headless GUI automation;
- macOS one-command installation using the official DipTrace application's
  bundled Wine runtime, with visible GUI and private hidden-Win32-desktop
  headless automation;
- permanent Linux and macOS clean-install CI gates in addition to the existing
  Windows installer/lifecycle and cross-platform test matrix.

## Platform evidence required before publication

The release is blocked until the exact candidate passes all applicable gates.
The intended platform statement is bounded to:

- **Windows:** existing split per-user/admin installer, portable bundle, bridge,

- **Linux:** Ubuntu 24.04 x86-64 clean installation; Wine; DipTrace 5.3.0.3;
  frozen MCP stdio; shared-prefix bridge; real Schematic GUI liveness under

Exploratory macOS run `31967736428` already demonstrated real DipTrace GUI

## Known limitations

- Windows executables remain unsigned development artifacts.
- Linux/macOS platform gates establish the exact tested host/runtime paths, not
  universal compatibility with every distribution/macOS/DipTrace version.
- The macOS hosted gate proves real GUI liveness, hidden-desktop isolation and
  automation readiness; it does not yet claim a full native `.dch`/`.dip`
  Save/Close/Reopen round-trip without a suitable native fixture/evidence case.
- Linux headless isolation uses a private Xvfb display; macOS headless isolation
  uses a private Win32 desktop inside DipTrace's bundled Wine prefix.
- Headless GUI isolation is not a process/filesystem/network/token/privilege
  sandbox.
- Native manufacturing generation, production readiness, Novarm/DipTrace
  endorsement, field-solver accuracy, PI/EMC/thermal sign-off and universal
  compatibility are not claimed.
