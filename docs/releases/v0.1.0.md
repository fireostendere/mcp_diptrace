## Unsigned-binary disclosure

No signing identity is configured. All 0.1.0 artifacts, including the Windows
bridge executable, are unsigned. CI success is not a code signature. Users
must verify `SHA256SUMS.txt` against the published hashes after download.

## Supported environments

- Python 3.10–3.13 on Linux, macOS, and Windows for the MCP server; offline
  XML analysis also works under WSL.
- Live integration requires Windows 10/11 and a DipTrace build that supports
  executable XML plug-ins.
- The wheel does not contain the PowerShell installer or plug-in settings;
  those ship as repository sources and are exercised by the Windows CI job.

## Known limitations

- Not a replacement for the DipTrace GUI or native EDA engine.
- Component and Pattern Editor bridge profiles are read-only.
- No native Gerber, NC Drill, ODB++, IPC-2581, or vendor production packages.
- Broad real-DipTrace open/save/re-export evidence remains incomplete; runtime
  `get_capabilities` is authoritative for a specific document and installation.
- No private conduct channel, contribution-provenance terms, independent
  reviewer, or signed artifacts yet; see the release checklist.

## Retention and rollback

- Release assets on GitHub Releases are immutable and are never replaced under
  the same version.
- If 0.1.0 is found defective, a new version is published or the release is
  withdrawn per the registry policy in
  [RELEASE_PROCESS.md](../RELEASE_PROCESS.md); the incident record follows that
  document's section 6.
