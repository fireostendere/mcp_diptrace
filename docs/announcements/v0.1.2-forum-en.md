# DipTrace MCP v0.1.2 — forum announcement

DipTrace MCP is a local MCP server and Windows bridge for working with DipTrace
XML from Codex, Claude Desktop, and other MCP clients. It is useful for
structured PCB and Schematic inspection, review, guarded edits, transaction
preview, SHA-256-bound commits, and explicit apply/cancel decisions.

Version 0.1.2 corrects release-document drift, adds installation from GitHub
Release assets, synchronizes generated coverage/format-coverage/MCP snapshot
metadata, and records v0.1.1 as withdrawn. It is an alpha/development-stage
release, not production-ready and not a replacement for DipTrace.

The documented scope includes:

- reading, review, and structured queries for PCB, Schematic, Component Library,
  and Pattern Library XML;
- guarded semantic edits, transaction preview, expected-SHA checks, and
  cancellation;
- Windows/WSL live integration for the tested PCB and Schematic matrix,
  including apply, cancel, wrong-SHA, and Windows-native exchange paths;
- controlled live acceptance with DipTrace 5.2.0.4 and separate schematic
  evidence for DipTrace 5.3.0.2;
- PCB and Schematic workflows with connectivity/count checks and independent
  save/re-export for the tested paths; and
- 159 registered MCP tools.

Evidence boundary: the public MCP workflow invokes 63 distinct tools. That does
not prove real GUI round trips for all 159 registered tools and does not mean
that all 159 tools were verified in DipTrace GUI. `get_capabilities` remains
the source of truth for a specific document and installation.

Validation results, exact test/coverage values, the complete CI matrix,
artifact audit, wheel↔sdist comparison, clean-wheel smoke, bridge provenance,
and live-acceptance boundaries are recorded in the [release record](../releases/v0.1.2.md)
and attached `LIVE_ACCEPTANCE_2026-07-31.md` and
`CODE_REVIEW_2026-07-31.md`. Publication was gated on checking the publicly
downloaded assets; links and hashes are in `SHA256SUMS.txt`.

Short installation:

1. download the wheel, sdist, `diptrace_mcp_bridge.exe`, Windows plug-in ZIP,
   and `SHA256SUMS.txt` from the [GitHub Release v0.1.2](https://github.com/fireostendere/mcp_diptrace/releases/tag/v0.1.2);
2. run `sha256sum -c SHA256SUMS.txt` or use PowerShell `Get-FileHash`;
3. install the wheel into a clean Python 3.12 environment;
4. unpack the plug-in ZIP, inspect all four settings profiles, and run
   `install_plugin.ps1` from elevated PowerShell when required; and
5. close the old bridge session and start a fresh one after updating.

The license is Apache-2.0. The Windows binary is unsigned; verify the GitHub
source and SHA-256. Known limitations include incomplete broad writer and
DipTrace-version coverage, read-only Component/Pattern Editor profiles, no
production or manufacturing sign-off, no package-index publication, and
unverified native-library/external-solver scenarios.
