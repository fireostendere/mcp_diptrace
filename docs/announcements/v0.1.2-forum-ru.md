# DipTrace MCP v0.1.2 — объявление для форума

DipTrace MCP — локальный MCP-сервер и Windows bridge для работы с XML-файлами
DipTrace из Codex, Claude Desktop и других MCP-клиентов. Проект нужен, чтобы
получать структурированный анализ PCB и Schematic, строить проверяемые
preview и выполнять ограниченные изменения с защитой SHA-256, transaction
preview и явным apply/cancel.

В v0.1.2 исправлены рассинхронизации release-документации, добавлен путь
установки из GitHub Release assets, синхронизированы generated coverage,
format-coverage и MCP snapshot, а предыдущий v0.1.1 помечен withdrawn. Это
development-stage/alpha релиз, не production-ready заявление и не замена
DipTrace.

Что работает в заявленных границах:

- чтение, обзор и структурированный поиск в PCB, Schematic, Component Library
  и Pattern Library XML;
- guarded semantic edits, transaction preview, проверка ожидаемого SHA-256 и
  отмена изменений;
- Windows/WSL live integration для проверенной матрицы PCB и Schematic,
  включая apply, cancel, wrong-SHA и Windows-native exchange path;
- controlled live acceptance с DipTrace 5.2.0.4 и отдельная schematic evidence
  для DipTrace 5.3.0.2;
- PCB и Schematic workflows, включая connectivity/count проверки и
  независимый save/re-export для проверенных путей;
- 159 зарегистрированных MCP tools.

Важно: public MCP workflow вызывает 63 distinct tools. Это не доказывает
реальные GUI round trips для всех 159 зарегистрированных tools и не означает,
что все 159 tools проверены в DipTrace GUI. Runtime `get_capabilities` остаётся
источником истины для конкретного документа и установки.

Результаты validation: exact test/coverage values, полный CI matrix, artifact
audit, wheel↔sdist comparison, clean-wheel smoke, bridge provenance и live
acceptance boundaries указаны в [release record](../releases/v0.1.2.md) и
прикреплённых `LIVE_ACCEPTANCE_2026-07-31.md` и
`CODE_REVIEW_2026-07-31.md`. Публикация выполнена только после проверки
публично скачанных assets; ссылки и SHA-256 находятся в `SHA256SUMS.txt`.

Короткая установка:

1. скачайте wheel, sdist, `diptrace_mcp_bridge.exe`, Windows plugin ZIP и
   `SHA256SUMS.txt` со страницы [GitHub Release v0.1.2](https://github.com/fireostendere/mcp_diptrace/releases/tag/v0.1.2);
2. выполните `sha256sum -c SHA256SUMS.txt` или проверьте `Get-FileHash` в
   PowerShell;
3. установите wheel в чистое Python 3.12 окружение;
4. распакуйте plugin ZIP, проверьте четыре settings profiles и запустите
   `install_plugin.ps1` из PowerShell Administrator;
5. после обновления закройте старую bridge session и создайте новую.

Лицензия — Apache-2.0. Windows binary unsigned; проверяйте источник GitHub и
SHA-256. Известные ограничения: неполная широкая совместимость writer paths и
версий DipTrace, read-only Component/Pattern Editor profiles, отсутствие
production/manufacturing sign-off, отсутствие package-index publication и
неподтверждённые external-solver/native-library сценарии.

Обычные bugs сообщайте через соответствующие issue forms. Security bugs
отправляйте только через private vulnerability reporting из [SECURITY.md](https://github.com/fireostendere/mcp_diptrace/blob/main/SECURITY.md),
не в публичные issues.
