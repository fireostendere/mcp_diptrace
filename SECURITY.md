# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities through GitHub private vulnerability
reporting:

<https://github.com/fireostendere/mcp_diptrace/security/advisories/new>

Do not disclose a suspected vulnerability in a public issue, pull request,
discussion, or forum post.

Include the affected version or commit, the artifact hash when relevant, a
reproduction or impact description, and whether proprietary design files are
involved. Do not attach proprietary, personal, or redistribution-restricted
design files; describe them instead.

## Scope

DipTrace MCP processes local DipTrace XML files and runs a local MCP server
and Windows bridge. Reports about unsafe file mutation, path handling,
trust-promotion bypass, or unintended network exposure are in scope. Reports
that require a licensed DipTrace installation should state the exact DipTrace
build.

## Response

The repository owner reviews private reports. No response-time or fix SLA is
claimed; the project is maintained by one person. Reporters are credited only
with their explicit permission.

## Preferred languages

English or Russian.
